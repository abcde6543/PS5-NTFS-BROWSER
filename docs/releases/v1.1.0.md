## NTFS Browser v1.1.0 for jailbroken PS5

Browse NTFS USB drives on a jailbroken PS5, and now **copy files onto them too**.

### Download
**`ntfs-browser.elf`**: send it to your ELF loader (port 9021, e.g. elfldr, or etaHEN's payload loader):

```sh
nc -q0 <ps5-ip> 9021 < ntfs-browser.elf
```

The PS5 browser opens on the file browser. You can also use `http://<ps5-ip>:8085` from a phone or PC.

### What's new in 1.1.0
- **Write to NTFS drives.** Copy files and folders from the console (or between drives) onto an NTFS USB drive, and create folders on it.
  - Writing is **off by default**. Turn it on per drive with the lock button next to it.
  - It only ever **adds** files and folders. Nothing already on the drive is changed, renamed or deleted.
  - It refuses drives Windows didn't unmount cleanly (dirty flag, Fast Startup hibernation, pending journal), the main cause of NTFS corruption from other systems.
  - Interrupted copies resume where they stopped.
- The copy dialog has a **destination drive** picker. Copying from the console defaults to the NTFS drive, and copying from the NTFS drive defaults to the console.
- **New folder** button on the console and on writable NTFS drives.
- Names Windows can't store (`: * ? " < > |`, trailing dots, `CON`…) are adjusted automatically.
- The free-space check before a copy now takes partly copied files into account.

### Testing
- **Writer:** tested on every cluster size from 512 B to 64 KB, with 5,000-file folders, Unicode and very long names, fragmented free space, file-table growth, a full disk, and alternating edits with ntfs-3g. Every result is verified by a structural checker, `ntfsresize --check`, and ntfs-3g reading back every file.
- **Reader:** compared byte for byte with ntfs-3g, and fuzzed with 300 corrupted images.

### Please note
- **Back up anything irreplaceable before allowing writes.** The writer has not yet been tested with Windows `chkdsk` on drives it has written, or on a real console.
- USB devices are expected as `/dev/da*`. If a drive isn't detected, use **Open image** with its device path.
- Encrypted (EFS) and BitLocker content can't be read.

Full details are in the [README](https://github.com/abcde6543/PS5-NTFS-BROWSER#readme).

## NTFS Browser v1.3.0 for jailbroken PS5

Browse, copy to and from, and now upload to NTFS USB drives on a jailbroken PS5.

### Download
**`ntfs-browser.elf`**: send it to your ELF loader (port 9021, e.g. elfldr, or etaHEN's payload loader):

```sh
nc -q0 <ps5-ip> 9021 < ntfs-browser.elf
```

The PS5 browser opens on the file browser. You can also use `http://<ps5-ip>:8085` from a phone or PC.

### What's new in 1.3.0
- **Read-write by default.** Clean NTFS drives are writable as soon as they're plugged in. Nothing is written until you actually copy, upload or create something, so a drive you only browse is never modified. Drives Windows didn't unmount cleanly (dirty, Fast Startup, pending journal) still start read-only, with the reason shown. The lock button still makes any drive read-only.
- **Upload from a PC or phone.** Drag files onto the page, or use the new **Upload** button, to send them straight to the PS5 or to the NTFS drive, with progress and speed. An interrupted upload to NTFS resumes when you send the same file again.
- **Search.** Type in the filter box and press **Enter** (or click 🔍) to find files by name in the current folder and all its subfolders.
- **Eject.** A button next to each NTFS drive finishes all writes so you can unplug it safely. Press **Rescan** to bring it back without unplugging.
- **Safer resume.** A partly copied file is only continued if its date also matches, so a different file with the same name and size is never stitched onto it.
- The sidebar shows each drive's state (Writable / Read-only) on its own line.

### Testing
- **Write stress tests:** every cluster size from 512 B to 64 KB, 5,000-file folders, fragmented and full drives, and alternating edits with ntfs-3g. Every result is verified by a structural checker, `ntfsresize --check`, and ntfs-3g reading every file back.
- **Server tests:** uploads (resumed, interrupted, refused), search, eject, and a check that merely browsing a writable drive leaves it byte-for-byte unchanged.

### Please note
- **Back up anything irreplaceable before writing to a drive.** The writer has not yet been tested with Windows `chkdsk` on drives it has written, or on a real console.
- Use **Eject** before unplugging a drive you've written to.
- The PS5's own browser can't pick local files, so upload from a PC or phone.
- USB devices are expected as `/dev/da*`. If a drive isn't detected, use **Open image** with its device path.
